# Python Development

Este repositório reúne exercícios e práticas de Python estudadas durante aulas e atividades práticas. O objetivo é reforçar conceitos básicos de programação, como entrada e saída de dados, laços de repetição, validação de valores e cálculos matemáticos.


## Como executar

Para rodar qualquer script Python, use o comando:

```bash
python "python fiap/exercicios praticos/1. lacos repeticao/ex1.py"
```

Você pode trocar o caminho do arquivo para executar qualquer outro exercício do projeto.

## Requisitos

- Python 3 instalado no sistema.
- Terminal ou editor com suporte para execução de scripts Python.

## Observação

Este projeto é uma coleção de estudos pessoais e acadêmicos, voltada para prática e revisão dos conceitos iniciais de Python.
